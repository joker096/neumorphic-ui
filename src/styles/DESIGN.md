# Design System Documentation

## Typography

- **Display:** Space Grotesk — headings, titles
- **Sans:** Inter — body text
- **Mono:** ui-monospace — code, crypto values

### Font Sizes
| Token | Size | Use |
|-------|------|-----|
| `--text-xs` | 12px | Labels, badges |
| `--text-sm` | 14px | Body text, inputs |
| `--text-base` | 16px | Primary content |
| `--text-lg` | 18px | Section headers |
| `--text-xl` | 20px | Large headings |
| `--text-2xl` | 24px | Hero text |

## Color System

### Dark Theme
- Background: `#0d1017` (primary) / `#13151b` (secondary) / `#1a1d24` (tertiary)
- Text: `#f0f2f5` (primary) / `#9ca3af` (secondary)
- Accent: `#f97316` (orange)
- Success: `#22c372` / Warning: `#f59f19` / Danger: `#ef4424`

### Light Theme
- Background: `#f8fafc` (primary) / `#f1f5f9` (secondary) / `#e2e8f0` (tertiary)
- Text: `#0f172a` (primary) / `#475569` (secondary)
- Accent: `#ea580c` (orange)
