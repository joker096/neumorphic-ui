# PWA Icon Generation

## Заглушка создана
- `icon.svg` — SVG-заглушка для PWA икона

## Как сгенерировать PNG:

### 192x192 (icon-192.png):
```bash
convert icon.svg -resize 192x192 icon-192.png
```

### 512x512 (icon-512.png):
```bash
convert icon.svg -resize 512x512 icon-512.png
```

### Или через онлайн-инструмент:
1. Откройте `icon.svg` в браузере
2. Скриншот или экспорт в PNG 192x192 и 512x512
3. Сохраните как `icon-192.png` и `icon-512.png`
