Security & Integrity

  • Source not disclosed. Only compiled, minified + obfuscated binaries are distributed. No debug symbols or source maps ship in production.
  • Signed binaries. Desktop builds are code-signed (Windows Authenticode, macOS notarization). Android APK/AAB are signed with the project keystore.
  • Verify before you run. Every file carries a SHA-256 checksum in CHECKSUMS.txt. Confirm it:

sha256sum -c CHECKSUMS.txt  ·  gpg --verify releases.json.asc releases.json

  • E2E encryption. X25519 ECDH + Ed25519 signatures + HMAC-SHA256. The server is never in the trust path.
  • No external tampering. CSP, HSTS, and strict CSP on desktop webviews block injection from outside.
