UIUX Messenger — Commercial Product UI
========================================

Это расширенный standalone визуальный прототип без backend/API.

Экраны:
- Dashboard / Overview
- Contacts
- Groups
- Channels
- Calls
- Notifications center
- Media Viewer
- Emoji & Stickers picker
- Settings
- Complete UI Kit

Дополнительно:
- responsive desktop/tablet/mobile
- единая design system
- states: hover, active, focus, online/offline, badges
- cards, dialogs, inputs, buttons, switches, chips
- коммерческая dark UI
- навигация между экранами
- демонстрационные действия и toast feedback

Запуск:
Откройте index.html в браузере.
Или:
python -m http.server 8080
и перейдите на http://localhost:8080
