## 3. Детализация разделов

### Интро
- Проблема: менеджеры живут в чате, а CRM отдельно → двойная работа.
- Решение: Mess&Anger = мессенджер + встроенная CRM в одном окне.
- Кнопка (`primary`) + бонус-кнопка (`ghost`).

### Раздел 1. Что такое CRM в Mess&Anger
- Определение: полноценная CRM в мессенджере с P2P-защитой.
- Ключевые абстракции: Люди / Сделки / Задачи / Роли.
- УТП-список (4-5 пунктов): на устройстве, без сервера, с шифрованием, с импортом, с ролями.
- `[note]` — для кого подходит (малый бизнес, отдел продаж 2-20 чел).
- `[photo 13]`.

### Раздел 2. Как открыть CRM
- Шаг за шагом (ol): открыть Mess&Anger → вкладка «Company Chat» (Адаптив) → вкладки People/Deals/Tasks/Roles.
- `[note]` — бесплатная версия открывает «Люди»; воронка/задачи/роли — в Premium.
- `[photo 13]`.

### Раздел 3. Люди: клиентская база
- Группы по отделам и клиентам, сворачивание, статистика группы (лиды, открытые задачи, сделки).
- Карточка контакта: имя, статус (lead/client/partner/vendor/internal/vip), должность, телефон, почта, отдел, менеджер, теги, заметки; кнопки «Позвонить/Видео/Сообщение».
- `[photo 14]`, `[photo 18]`.
- `[warning]` — не путать статусы; статус определяет воронку.

### Раздел 4. Воронка сделок
- Kanban из 6 стадий: New, Qualified, Proposal, Negotiation, Won, Lost.
- По каждой стадии: сумма + прогресс-бар. Перетаскивание карточек между стадиями.
- Карточка сделки: контакт, сумма, валюта, ответственный, ожидаемая дата закрытия, заметки.
- `[photo 15]`, `[photo 21]`.
- `[note]` — сумма открытых сделок без «Lost» = прогноз выручки.

### Раздел 5. Задачи
- Список: открытые первыми, сортировка по дате. Галочка выполнения. Приоритет (низкий/средний/высокий). Исполнитель, связанный контакт, дедлайн.
- `[photo 16]`.
- `[quote]` — гипотеза «задача не выполняется, если у неё нет дедлайна и владельца».
- `[html]` — простая арифметика: задача = минимум 4 поля.

### Раздел 6. Роли и права
- Системные роли: admin (все права), manager (сделки, задачи, сотрудники, назначение менеджеров), member (просмотр).
- 8 прав: viewAll, manageMembers, manageDepartments, manageRoles, manageCompany, manageDeals, manageTasks, assignManagers.
- Кастомные роли (HR, Finance как пример): набор прав поверх системной.
- `[photo 17]`, таблица «роль → права».

### Раздел 7. Поиск и фильтры
- Глобальный поиск по людям/сделкам/задачам, переход кликом прямо в карточку с подсветкой.
- Фильтры: роль, отдел, статус, тег, «назначено мне»; бейдж количества активных фильтров.
- `[simple_tooltip]` — что означает фильтр-значок.
- `[photo 19]` (фильтры открыты), `[photo 20]` (поиск).
- `[note]` — фильтры хранятся локально и сбрасываются при перезагрузке.

### Раздел 8. Безопасность
- Все данные CRM шифруются AES-256-GCM на устройстве (ключ привязан к установке).
- Никакого облачного сервера: контакты и сделки не покидают устройство иначе как по явному экспорту.
- Синхронизация команды — сквозное шифрование через групповой ключ компании.
- `[warning]` — резервная копия/экспорт ответственности владельца.
- `[note]` — преемственность с P2P-моделью мессенджера.

### Раздел 9. Импорт/экспорт
- Импорт: CSV (в т.ч. русские заголовки: имя/телефон/сделка/статус), JSON, расшифровка и автоопределение. Превью и список проблем перед применением. Дедупликация по телефону/почте/имени + тег `imported:<источник>`.
- Экспорт: Contacts CSV, Deals CSV, Tasks CSV, Company JSON. Шифрованный `.enc` бандл для переноса в другой браузер/устройство.
- `[code]` — пример CSV-строки.
- `[photo 22]`.
- `[warning]` — пароль от `.enc` не восстановить.

### Раздел 10. Интеграции
- Веб-виджет: посетитель сайта заполняет форму → контакт автоматически попадает в CRM с меткой сайта (отдельно от личных/бизнес-контактов) → лид в воронке.
- Коннекторы (опционально, по токену): Bitrix24, amoCRM, экспорт Telegram-контактов (contacts.json).
- SDK `window.MessAnger`: импорт, экспорт бандла, чтение контактов/сделок/задач/аналитики.
- `[photo 23]` (инвайт-код и QR для команды).
- Таблица «интеграция → что даёт».

### Раздел 11. Сравнение
- Таблица: Mess&Anger CRM vs Bitrix24 vs amoCRM vs Google Таблицы.
- Критерии: цена, шифрование, место хранения, воронка, задачи, роли, импорт CSV, работа в мессенджере, е2е-команда.
- Вывод: для малого бизнеса и приватности — встроенная CRM.
